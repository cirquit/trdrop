# TRDrop v2

视频帧率、帧时间与画面撕裂分析工具，适用于采集卡录制的视频素材。

支持最多 4 个视频并排对比分析。自动检测 HDR（PQ/HLG）内容并转换为 SDR 以确保输出画面颜色正确。

## 环境配置

```bash
uv sync              # 仅安装运行时依赖
uv sync --all-extras # 安装开发工具
```

## 启动

```bash
uv run trdrop
```

## 使用说明

### 快速上手

1. 启动应用，你会看到一个带有顶部控制栏的空白窗口
2. 点击 **"+"** 或拖拽视频文件到窗口中（最多 4 个视频）
3. *（可选）* 点击 **"Video..."** 设置输出视频路径，点击 **"CSV..."** 设置指标导出路径
4. 点击 **"Start"** 开始处理
5. 等待进度条到 100%，或点击 **"Pause"** 暂停后逐帧检查

### 控制栏

从左到右依次为：

| 控件 | 说明 |
|------|------|
| 状态指示器 | 彩色圆点显示引擎状态（灰色=空闲，蓝色=就绪，绿色=处理中，橙色=暂停，紫色=完成，红色=错误） |
| **"+"** | 添加视频文件（支持 MP4、MKV、AVI、MOV、WebM），可多选，最多 4 个 |
| **"-"** | 移除最后一个已加载的视频 |
| 视频计数 | 显示当前已加载的视频数量（0-4） |
| **"CSV..."** | 设置 CSV 导出路径。导出逐帧指标（帧率、帧时间、重复帧检测等） |
| **"Video..."** | 设置视频导出路径。导出带叠加层的合成视频（MP4） |
| **"Config..."** | 加载或保存 YAML 预设文件，用于自定义叠加层样式（见[预设配置](#预设配置)） |
| **"Profile"** | 启用性能分析。处理完成后生成 `trdrop_profile.csv` 和摘要报告 |
| **"Start"** | 开始处理（加载视频后可用） |
| **"Pause"** / **"Resume"** | 暂停或恢复处理 |
| **"Reset"** | 清除所有内容，回到空闲状态 |
| Seek 输入框 + **"Seek"** | 跳转到指定帧（暂停或完成状态下可用） |

### 菜单栏

- **File > Add Video...** (Ctrl+O / Cmd+O) — 同 "+" 按钮
- **File > Quit** (Ctrl+Q / Cmd+Q) — 退出应用
- **Help > About** — 版本信息

### 拖放导入

直接将视频文件拖拽到窗口中即可加载。支持格式：MP4、MKV、AVI、MOV、WebM。

### 工作流程

1. **加载视频** — 使用 "+" 按钮、菜单或拖放
2. **配置导出** — 设置 CSV 和/或视频输出路径（可选，但至少设置一个才有输出）
3. **加载预设** — 点击 "Config..." 加载 YAML 预设文件来自定义叠加层样式（可选）
4. **开始处理** — 预览区域实时显示带 FPS 叠加层的合成画面
5. **检查帧** — 暂停处理，输入帧号，点击 "Seek" 查看该帧的指标数据
6. **查看结果** — 处理完成后，查看导出的视频和/或 CSV 文件

### 输出内容

- **视频 (.mp4)** — 合成视频，包含所有已加载视频的网格排列、FPS/帧时间文字叠加层以及可选的 FPS 曲线图
- **CSV (.csv)** — 每帧每视频一行，字段包括：frame_index、is_duplicate、diff_ratio、windowed_fps、smoothed_fps、frametime_ms 等

## 预设配置

TRDrop 使用 YAML 预设文件控制叠加层的外观。点击控制栏中的 **"Config..."**：

- **"Yes"** — 加载已有的 YAML 预设文件
- **"No"** — 将默认预设保存为模板供编辑

完整参数说明和注释请参见 `trdrop_preset.example.yaml`。

### 核心概念

- **坐标** 使用 0.0–1.0 归一化表示（0.5 = 画面中心）
- **参考系** 可以是 `global`（相对于整个输出画面）或 `video:N`（相对于第 N 个视频的区域）
- **颜色** 使用 RGBA 数组 `[R, G, B, A]`，取值范围 0–255

## HDR 支持

TRDrop 自动检测 HDR 视频内容（PQ/HLG 传输曲线、BT.2020 色彩空间）并进行 SDR 色调映射，确保显示和导出颜色正确。处理流程包括：

- PQ EOTF（感知量化器）解码
- BT.2020 到 BT.709 色域映射
- Reinhard 色调映射
- BT.709 伽马编码

无需任何配置——HDR 检测和转换全自动完成。
